🍳 AI Recipe Maker

An AI-powered web application that generates recipes based on ingredients entered by users. Built using Flask and integrated with AI APIs to deliver smart and real-time cooking suggestions.

🚀 Features
🥕 Enter available ingredients to get recipe suggestions
🤖 AI-powered recipe generation using external API
⚡ Lightweight Flask backend
🔒 Input validation for safe requests
🌐 Simple and responsive frontend
🛠️ Tech Stack
Backend: Flask (Python)
Frontend: HTML, CSS, JavaScript
AI Integration: External AI API
Architecture: REST-style backend (stateless design)
📁 Project Structure
Ai-recipe-maker/
│
├── index.html        # Frontend UI (HTML)
├── style.css         # CSS + JavaScript (UI logic if included)
├── app.py            # Flask backend application
└── README.md         # Project documentation
⚙️ How to Run the Project
1. Clone the repository
git clone https://github.com/AEZIN786/Ai-recipe-maker.git
cd Ai-recipe-maker
2. Install Flask
pip install flask
3. Run the application
python app.py
4. Open in browser
http://127.0.0.1:5000
🔐 API Key Setup (if used)

If your project uses an AI API, add your key inside app.py or environment variables:

AI_API_KEY=your_api_key_here
